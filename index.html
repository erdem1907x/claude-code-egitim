Claude Code Nedir?

Terminal üzerinden çalışan, Anthropic tarafından geliştirilen yapay zeka destekli kodlama asistanı.

🤖

Yapay Zeka Asistanı

Doğal dille komut verirsin, Claude Code kodu yazar, dosyaları düzenler, hataları düzeltir.

💻

Terminal Tabanlı

Komut satırından çalışır. Kurulum basit, kullanım güçlü. Her işletim sisteminde çalışır.

🎯

Vibe Coding

"Bir alışveriş sitesi yap" dersin, Claude Code tüm dosyaları oluşturur ve çalıştırır.

🔧

Güçlü Araçlar

Dosya okuma, yazma, terminal komutları, web arama ve çok daha fazlasına erişir.

Eğitim Konuları

Başlıklara tıklayarak alt konuları genişlet ve öğrenmek istediğin konuya git.

Vibe Coding ile Hızlı Başlangıç

Adım adım ilk projenizi oluşturun.

1

Node.js Kur

nodejs.org adresinden Node.js'i indirip kur. Bu adım Claude Code için zorunludur.

node --version
2

Claude Code'u Yükle

Terminal ya da Komut İstemi'ni aç ve aşağıdaki komutu çalıştır.

npm install -g @anthropic-ai/claude-code
3

Klasörüne Git

Proje klasörünü oluştur ve o klasöre gir.

mkdir projem && cd projem
4

Claude Code'u Başlat

Tek komutla yapay zeka asistanını çalıştır.

claude
5

İlk Komutunu Ver

Doğal Türkçe ile ne yapmak istediğini söyle.

Basit bir yapılacaklar listesi uygulaması oluştur
